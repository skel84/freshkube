- **Workloads uses the shared table:** the Workloads Health list is drawn by the same table as Pods, with its header, 26 dp rows and a glyph column in place of the Status tag (the word, such as Failing, is the glyph's tooltip). At narrow widths and large text sizes the Kind, Ready / restarts and Issue columns are no longer cut off: the table scrolls sideways and keeps each row's glyph and name at the left edge. Selection follows the namespace, workload or pod by identity, so a filter that moves it keeps it selected.
