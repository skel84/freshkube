- **Application Timeline, Syncs:** an application's Timeline tab now reads its Argo CD Applications from the open cluster. The Syncs chip lists each Application's last sync that ran in the window, with its phase, revision and retries, and says what it could not see (Applications read through another connection, a listing cut at the page cap, a refused listing). It shows the latest state only, so it never counts as a quiet hour. Read-only.
