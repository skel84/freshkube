- **Notifications, banners:** a notice that shows can now reach you as a system banner while Freshkube isn't the front app, once the system allows it (asked once, at the first follow, never again after a refusal); in front, or without permission, it is a toast as before. Clicking a banner opens the item, a pod on its Events or the page that holds a change or an incident, in the cluster that is open. Settings › Notifications says where the permission stands. This build has no native macOS sink yet, so it still shows toasts.
