- **Waiting to ship:** a second row under Changes in the Applications column lists, for each Kargo application, the Freight that is built or deployed somewhere but not yet in production, with its pull request, when it was merged, how long it has waited since it reached the Stage before production and why it is stuck. A project that fans out to several production Stages shows the furthest behind. The find box takes a pull request number or a commit and traces it to production, and the Inspector says what promoting now would ship. It is read-only and reads only while shown, from Kargo's Freight and Stages and one GitHub call for each Freight in a gap ([docs/features/applications.md](docs/features/applications.md)).
