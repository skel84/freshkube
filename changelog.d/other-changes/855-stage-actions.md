- **Stage actions:** the change page's Stage Inspector can Refresh a Stage or its Warehouse, Reverify a Stage, Promote the change's Freight to it and Abort a running Promotion, through the write framework. Promote shows what the Stage runs now against what it would run and asks for the Stage's name on a protected cluster; the level is the stricter of the Kargo cluster's and the Stage's destination's. Refresh and Reverify only add an annotation and ask nothing, and are still audited. Read-only clusters block them all.
