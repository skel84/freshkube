- **Database explorer:** Explore on a CloudNativePG database in Databases opens a read-only session to a ready replica through a port forward, with a schema browser that reads each schema when opened and a table's first 200 rows. The session is read-only (`BEGIN READ ONLY` per request, `SET`, `BEGIN` and `COMMIT` refused), sets its own timeouts, and reads one login Secret per connection, the team's reader Secret first and then the operator's app user, never the superuser's. Writes are shown as a later slice ([docs/features/database-explorer.md](docs/features/database-explorer.md)).
