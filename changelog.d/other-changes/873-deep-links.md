- **Deep links:** Copy link (⇧⌘C, the object pane, the Go menu and an attention row's menu) gives a `freshkube://open?…` link to the view shown, and ⌘K or `--open-link` opens one, read with your own access; a link that can't be followed says why in the pane (can't read, not found, not served, replaced). A link carries the cluster's fingerprint, not a context name, and is matched to your own clusters: one match opens there, several or a CA-only match ask first, none says so; the window never switches unasked, and Settings shows each cluster's fingerprint (`fingerprint:` in `freshkube.yaml` overrides it for clusters behind a proxy). A link only navigates. The change page's link is now Copy Kargo link. Links opened from the system work on macOS (the app registers `freshkube://`), on Linux (the tarball's desktop entry) and on Windows (a registry template ships in the zip), and `freshkube <url>` opens one. See [deep links](docs/features/deep-links.md).
