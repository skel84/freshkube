- **Setup file:** at the first launch of this version, `workspace.json` and `coroot.json` move once into `freshkube.yaml` beside the preferences. The old files are kept as `workspace.json.bak` and `coroot.json.bak`, an existing backup is never replaced, and nothing moves if `workspace.json` can't be used. Coroot's reconnect flag moves to `preferences.json`, and a metrics source chosen for a workspace cluster is copied into that cluster's entry.
