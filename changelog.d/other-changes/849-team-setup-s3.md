- **Team setup, real fetches:** Freshkube can now read a team's shared setup file from a git repository, with your own `git` and sign-in, or from an HTTPS address. A fetch runs nothing from the repository, refuses a key file that is a link or leaves the repository, refuses plain HTTP and a redirect to another host, and is bounded in time and size. The Team setup page still shows example data; joining from the app comes next.
