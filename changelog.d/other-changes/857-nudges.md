- **Refresh, reconcile and renew:** the Resources page can ask Argo CD to refresh an Application (or hard refresh it), ask Flux to reconcile a Kustomization, HelmRelease or source, and ask cert-manager to renew a Certificate, from the row menu, a key or the toolbar. Each asks first at every level that allows writes, shows the field and value it sends, can't be undone, and says "Accepted, but not seen to take effect after 30 s" if the controller has not answered by then. A read-only cluster sends nothing ([#857](https://github.com/skel84/freshkube/issues/857)).
