- **Refresh, reconcile and renew:** the Resources page can ask Argo CD to refresh an Application (or hard refresh it), ask Flux to reconcile a Kustomization, HelmRelease or source, and ask cert-manager to renew a Certificate, from the row menu, a key or the toolbar. Each asks first at every level that allows writes, shows the field and value it sends, can't be undone, and says "not seen yet" if the controller has not answered within 30 seconds. A read-only cluster sends nothing ([#857](https://github.com/skel84/freshkube/issues/857)).
