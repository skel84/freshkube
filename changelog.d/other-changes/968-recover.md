- **Recovering after sleep, a lapsed login and a network change:** the Kubernetes summary builds its client again, once, when the first read is refused as unauthorized (an expired token), and then shows a refusal the server repeats instead of retrying it. Node log follows reopen after the machine wakes, from that moment on. On macOS a network change (a VPN coming up, a move between networks) refreshes what is shown and the session's reads once. The stress run can raise only refused requests for its first minutes, so a short run shows a refused list recover.
